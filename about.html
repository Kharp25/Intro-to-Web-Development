About this project

I created this website for my IT 3203 Web Development class to share my research on web browsers. The project explores how browsers have evolved, how they turn web code into the pages we use, and how they support security, privacy, and performance. It also examines emerging developments, including AI-assisted browsing.

Through this project, I am applying HTML and CSS to organize research into a clear, accessible website while developing my web development skills.
