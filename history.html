Browser history

From an editable document viewer to an application platform.

The first browser

Tim Berners-Lee proposed the World Wide Web at CERN in 1989. By the end of 1990, he had developed a browser and server. The original browser, WorldWideWeb, could edit documents as well as display them.

In 1993, CERN made the Web software available on a royalty-free basis. That decision helped other people adopt and develop the technology.

A wider audience

NCSA Mosaic appeared in 1993 and helped bring graphical browsing to a wider audience. Netscape and Internet Explorer followed during the 1990s, when competition between browser vendors shaped the features developers could use.

Differences between implementations also created compatibility problems. A page built for one browser could behave differently in another.

Shared standards

Modern browser development depends on shared specifications and interoperability testing. Standards give developers a common foundation, although browser support and implementation details can still differ.
