Seven key concepts

A short glossary for the research.

Rendering engine
The browser component that interprets web content and helps produce the visible page. Different engines can implement the same standards in different ways.
Document Object Model (DOM)
A tree of objects representing an HTML document. Scripts can read or change it to update page content.
CSS Object Model (CSSOM)
An object representation of CSS rules. The browser uses style information together with the DOM when deciding how to display elements.
HTTP and HTTPS
HTTP defines requests and responses used to transfer web resources. HTTPS uses a protected connection to help keep those exchanges private and detect tampering.
Sandbox
A restricted execution environment that limits a process’s access to the rest of the system.
Same-origin policy
A rule that restricts interactions between resources from different origins. An origin consists of a scheme, hostname, and port.
Cache
Stored copies of resources that can be reused. Caching can reduce repeat downloads, but resources must be refreshed when needed.
